# Zclip Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Search the zclip clipboard archive with instant in-memory fuzzy filtering
- Split view: a one-line summary per entry on the left, the full content on the right
- Image entries show as `Image (WxH)` and preview their thumbnail via `zclip thumb`
- Filter entries by tag via the search bar dropdown
- Paste or copy any entry, text or image, to the frontmost app
- Add tags on entries by picking an existing tag or creating a new one, and remove tags
- Start the zclip polling daemon in the background
